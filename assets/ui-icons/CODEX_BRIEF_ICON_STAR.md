# 問題集UI アイコン `ic-star.png` の描き直し（Codex / image-2）

## なぜ描き直すか

いまの `ic-star.png` は**星の下に曲がりくねった道**が描かれている。
元の指示書（`assets/quest/CODEX_BRIEF_ICON_PROTO.md`）が
「星、**または**旗の立った小道（おすすめルート）」と2案を並べて書いたため、
codex が両方を1枚に描いた。

このアイコンは「**前回のつづき**」と「**おすすめ順で解く**」の2箇所で使う。
道が入っていると何の記号か伝わらず、小さい表示（52px）では
ただのノイズになる。**星ひとつだけ**にする。

## 保存先

```
C:\Users\user\projects\education-apps\pdf-workbook\assets\ui-icons\ic-star.png
```

生成した最新PNGをこのパスへ上書きコピーする。できたらパスとサイズだけ報告。

## 描くもの

**星ひとつだけ。** ほかには何も描かない。

- 5角の星。角は少し丸みをつけてやわらかく
- 星は**バッジの中央**。左右上下の余白を均等に
- ❌ 道・小道・軌跡・尾・キラキラの粒・旗・リボン・複数の星 — **すべて入れない**

## スタイル（既存4枚と完全にそろえる）

並べる相手は同じフォルダの `ic-ana.png` / `ic-qa.png` / `ic-yon.png` / `ic-doc.png`。
**この4枚を必ず参照し、線の太さ・角丸・余白・光の当たり方をそろえること。**

- フラットなミニ・イラストアイコン。角丸の正方形バッジの中に図がひとつ
- 配色は温かいブランド配色のみ。ベース=クリーム(#fdf3e3)〜淡いアイボリー、
  主役=ブランド茶(#b45309)＋アクセントに琥珀(#f59e0b)。3色程度に絞る
- やわらかい影・軽いグラデーションでほんの少しだけ立体感。派手にしない
- **バッジの外は完全な透明**（PNGアルファ）
- **文字・数字は入れない**
- 正方形 512×512

## 反映のしかた（画像ができたあと）

`generate_workbook_web.py` の `UI_ICON_KEYS` に `"star"` を戻す。
いまは画像が使えないので、素のSVGの星（`IC["star"]`）で描画している。

```python
UI_ICON_KEYS = ("star", "ana", "qa", "yon", "doc")
```

戻したら `python -X utf8 deploy_tsudumon.py --only wb` で再生成し、
`/wb/05/` の「やり方をえらぼう」で2箇所とも星ひとつに見えることを確認する。
