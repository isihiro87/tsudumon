### 実装時に本番キーで確かめた仕様（触るときはここを崩さない）

`/v1/responses`（Responses API。Chat Completions ではない）を使う。

| 事項 | 実際の挙動 | 対応 |
|---|---|---|
| `temperature` | gpt-5.6 系は **400 で拒否**（`Unsupported parameter`） | 送らない |
| `reasoning.effort` | 既定だと**推論トークンが出力枠を食う**。`classify`（上限32）は本文ゼロで失敗した | 既定 **`none`**（推論0・1〜2秒）。env `OPENAI_REASONING_EFFORT` で上げられる |
| `tools[].strict` | 未指定だと **自動で `true`**（`required` 必須になる） | 明示的に `false` |
| `output` | `reasoning` / `message` / `function_call` が混在する配列 | `message.content[].output_text` を連結、`function_call.arguments` は JSON文字列をパース |
| 打ち切り | `status:"incomplete"` ＋ `incomplete_details.reason:"max_output_tokens"` | `truncated: true` |
| usage | `input_tokens` / `output_tokens` / `input_tokens_details.cached_tokens` | そのまま計上（キャッシュ割引が効く） |
| 保存 | 既定は `store: true` で30日保持 | **`store: false`**（中学生の会話をOpenAIに残さない） |

- **音声は扱えない**（Responses API が受け付けない）。`llmProvider.generateText` が
  音声つきの呼び出しだけ **Gemini の最安モデルへ自動で振り替える**。触らないこと。
- プロンプトキャッシュは効いている（実測 1,870入力トークンのうち **1,847がキャッシュ**）。
  `aiChatPrompt.ts` の「不変ブロック → 可変ブロック」の並びが前提なので崩さない。
- 実機E2E確認済み: 通常質問／ツール発火（`remember` で `nextTestDate`）／履歴の引き継ぎ／分類。

## リッチメニューの動作（2026-07-26 適用・確定）

適用済み: `richmenu-3293e78bffe71b453e8464c56ac54e66`（画像 `pro-f.png`）。

| 位置 | ラベル | 動作 |
|---|---|---|
| 左上 | 教材をひらく | **uri** `tsudumon.jp/map/?from=menu`（1タップで即開く） |
| 中上 | テストの予定 | **uri** `tsudumon.jp/settings/#exam` |
| 右上 | まちがえを復習 | message「復習する」 |
| 左下 | 3日間無料でためす | uri `account/?do=trial`（record版では message「いまの学習状況を教えて」） |
| 中下 | 届く曜日・時間 | **uri** `tsudumon.jp/settings/` |
| 右下 | お支払い・解約 | **uri** `tsudumon.jp/account/` |

**なぜ左上を postback → uri に変えたか**（ユーザー指摘）: postback だとBotの返信を待って
もう1タップ必要で「すぐ開かない」。uri なら即開く。**「つづきから／ぜんぶから選ぶ」の選択は
マップページ上部の「つづきから」バー**で出す（`generate_tsudumon_portal.py` の
`renderResume()`。localStorage の進捗から計算するのでサーバ待ちゼロ・`paint()` の
`.current` ハイライトと必ず一致する）。

`tzm_open` postback と `tsudumonOpenMaterial.ts` は**残してある**（「教材をひらく」と
打たれたときの受け口。テスト範囲・間違いの残りを見たサーバ側のおすすめを返せる）。

**設定ページとお支払いページは分離した**（ユーザー指摘: 「届く曜日・時間」を押して
お支払い画面が出ると驚く）:
- `/settings/` … お知らせの曜日・時刻 ＋ **テストの予定（日付＋19単元チェック）**
- `/account/` … ご利用状況・お支払い・解約（配信設定のUIは撤去し `/settings/` へのリンクのみ）

テストの予定は **Web（`tsudumonExamSetting`）とチャット（`setExamScope` ツール）の両方**から
設定できる。保存先は同じ `users/{uid}.tsudumonExam`、検証も同じ `validateExam` を通す。

**マップの「つづきから」はまだ端末ローカルのまま**。教材ページを1回開けば復元されるので、
実用上は「日次配信のリンク → 教材 → 復元 → マップも正しい」でつながる。
マップ自体に認証を足すのは、即開くという利点を損なうので見送った。
