# つづもん 公開キャンペーン「8月15日まで無料でおためし」

作成 2026-08-03。**キャンペーンを終えるときに戻す場所の一覧**。
文面だけ残ると嘘になるので、ここを見ながら片付ける。

## ルール

| 項目 | 値 |
|---|---|
| 登録の締切 | **2026-08-11 23:59:59 JST** まで（ここまでに始めた人が対象） |
| 使える期限 | **2026-08-15 23:59:59 JST** |
| 8/12以降に登録 | 通常どおり **72時間（3日間）** |

締切ぎりぎり（8/11 23:59）に始めても 8/15 まで使えるので、
通常運用（72時間＝8/14まで）より短くなることはない。

## 実装（正本）

`marutto-study/functions/src/tsudumonCore.ts`

```ts
TSUDUMON_TRIAL_CAMPAIGN_ENTRY_END_MS  // 登録の締切
TSUDUMON_TRIAL_CAMPAIGN_UNTIL_MS      // 使える期限
computeTsudumonTrialExpiresAtMs()     // 体験の期限を決める
tsudumonTrialMaxDays()                // Stripe の trial_period_days の丸め
```

**コードは戻さなくてよい。** 日付を過ぎれば自動的に通常運用（72時間）へ戻る。
定数を消すと切り替え忘れが起きるので、**過去日時のまま残す**こと。

> ⚠️ `tsudumonTrialMaxDays()` は飾りではない。ここが 3 に固定されていると、
> 体験を延ばしたときに **「8月15日まで無料」と言いながら3日後に課金**される。
> 無料期間中の請求はいちばんやってはいけない事故なので、触るときは
> `__tests__/tsudumonTrialCampaign.test.ts` を必ず通す。

## 日数を書いていない場所（戻す必要なし）

体験リマインド（`tsudumonTrialReminder.ts`）は、キャンペーンに合わせて
**文面から日数の記述を外した**（「3日間おつかれさまでした」→「おつかれさまでした」）。
体験の長さは実装が決めるので、文面に日数を書かないほうが安全。ここは戻さない。
